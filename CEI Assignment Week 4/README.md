# Week 4 - Azure Cloud Fundamentals & Azure Data Factory

## Overview
Worked with Azure Storage Account, Blob Containers, and Azure Data Factory to build an end-to-end data pipeline.

## Activities Performed
- Created Resource Group and Storage Account
- Created Blob Container and uploaded Superstore dataset
- Created Azure Data Factory
- Configured Linked Service with Blob Storage
- Created Source and Destination Datasets
- Implemented Get Metadata activity for file validation
- Implemented Copy Data activity for data movement
- Executed and monitored pipeline execution
- Verified output file generation in Blob Storage
- Explored IAM roles and permissions

## Outcome
Successfully copied data from source CSV to destination CSV using Azure Data Factory and verified the output in Azure Blob Storage.

## Key Learning
Gained hands-on experience with Azure Storage, Azure Data Factory, Linked Services, Datasets, Metadata Validation, Copy Activity, Pipeline Execution, Monitoring, and IAM concepts.
